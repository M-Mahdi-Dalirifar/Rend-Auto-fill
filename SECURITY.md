# Security Policy

## Supported versions

Security fixes are applied to the latest code on `main`.

## Reporting a vulnerability

Please do not open a public issue for vulnerabilities involving credentials,
OAuth flows, private documents, or unintended data disclosure. Use GitHub's
private vulnerability reporting feature for this repository. If that feature
is unavailable, contact the maintainer through the address listed on the
maintainer's GitHub profile.

Include reproduction steps, affected versions, impact, and any suggested
mitigation. Do not include real tokens, resumes, or private spreadsheet data.
