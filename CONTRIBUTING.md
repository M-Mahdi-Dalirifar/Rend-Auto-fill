# Contributing

Thank you for helping improve this project.

## Before starting

- Search existing issues and pull requests.
- Open an issue before large behavioral or architectural changes.
- Never commit personal data, OAuth tokens, API keys, resumes, or private spreadsheet content.

## Local development

1. Fork and clone the repository.
2. Create a focused branch from `main`.
3. Load the project as an unpacked extension from `chrome://extensions`.
4. Exercise the changed flow on a non-sensitive test page or test sheet.
5. Run the repository validation workflow locally where practical.
6. Submit a pull request describing the behavior change and manual verification.

Keep changes small and preserve the extension's least-privilege permissions.
